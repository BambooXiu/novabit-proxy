# NovaBit Proxy

NovaBit Proxy 是一个跨平台 Electron 桌面应用（macOS / Windows），用于管理 VPS 上的 Xray 代理服务，支持 ISP 代理与 VPS 直连模式切换，并生成 VLESS + Reality 客户端配置。

当前版本：**1.2.16**

## 功能

- 一键部署 Xray-core、VLESS + Reality 和双模式配置
- 在 ISP 代理与 VPS 直连之间安全切换
- 查看 SSH、Xray 服务状态和当前出口 IP
- 部署即应用全部服务端优化（BBR、连接池策略、嗅探、分流规则），无需额外操作
- 仪表盘提供“修复并优化配置”操作，用于就地升级旧配置或重应用内核参数
- 生成 VLESS 链接、二维码和可导入 v2rayN/v2rayNG 的完整 JSON
- SSH 自动重连、远程命令超时和 Xray 操作串行化
- 配置写入前校验，服务启动失败时自动回滚

## 环境要求

本地开发或构建需要 Node.js 和 npm。远程 VPS 建议使用 Debian/Ubuntu 系统，并满足以下条件：

- SSH 用户具有安装软件、修改 sysctl 和管理 systemd 服务的权限（通常为 root）
- TCP 443 端口可用
- 部署时准备好 ISP SOCKS5/HTTP 代理信息

## 使用流程

1. **配置 VPS**：在“设置”中填写主机、SSH 端口、用户名和密码或私钥路径。
2. **配置 ISP 代理**：填写代理地址、端口、用户名和密码。
3. **一键部署**：进入“部署”页面点击“开始部署”。应用会安装 Xray、生成 Reality 凭证、写入双模式配置、配置防火墙并启动服务。
4. **导入客户端**：进入“客户端”页面重新生成配置。二维码或 VLESS 链接只包含节点参数；需要国内直连、DNS 分流等规则时，应复制完整 JSON 并在 v2rayN/v2rayNG 中本地导入。
5. **切换模式**：在“仪表盘”中选择“ISP 代理”或“直连”。切换会校验配置并在服务启动失败时回滚。

## “修复并优化配置”如何使用

> **通常不需要使用。** 一键部署生成的配置已包含全部优化项，部署完成即处于最优状态。

入口位于：**仪表盘 → 快速操作 → 修复并优化配置**。

点击后，应用会自动建立 SSH 连接，并依次执行：

- 写入并验证 `net.ipv4.tcp_congestion_control=bbr`、`net.core.default_qdisc=fq` 和 `net.ipv4.tcp_fastopen=3`
- 检查内核实际返回的拥塞控制、队列和 TCP Fast Open 状态
- 更新 Xray 连接策略，迁移旧版 DNS 配置
- 将新配置写入临时文件并执行 `xray run -test` 校验
- 原子替换正式配置，重启 Xray 并检查服务健康状态
- 新配置启动失败时恢复操作前的备份配置

### 什么时候使用

- 从旧版本应用升级后，已有 VPS 需要同步新的服务端优化
- 以前手动维护过 Xray 配置，或怀疑旧 DNS 配置仍在生效
- 需要确认 VPS 内核是否真正启用了 BBR、`fq` 和 TCP Fast Open
- VPS 内核参数被重置（例如更换过内核）

### 与重新部署的区别

| | 修复并优化配置 | 重新部署 |
|---|---|---|
| UUID / 密钥 / shortId | 不变 | **全部重新生成** |
| 客户端配置 | 不受影响 | **全部失效，需重新导入** |
| Xray 本体 | 不重装 | 重装 |
| 耗时 | 数秒 | 数分钟 |

**不要用重新部署来代替修复优化**——部署会重新生成凭证，导致所有客户端配置失效。

优化不是每次连接前都必须执行的操作。它会短暂重启 Xray，请避开通话、文件传输等不能中断的场景；VPS 账号还必须有修改系统参数和重启服务的权限。优化不能解决 VPS 路线、ISP 代理质量或本地网络造成的速度限制。

### 优化后是否需要更新 VLESS 链接

优化只更新 VPS 的网络参数和服务端配置，**VLESS 链接不会改变**。如果使用完整 JSON 客户端配置，建议在“客户端”页面重新生成并重新导入完整 JSON，以同步当前版本的客户端 DNS 分流规则；单独导入旧 VLESS 链接不会包含这些规则。

### 优化失败怎么办

先查看通知中的失败步骤，确认 SSH 连通性、VPS 权限、内核能力和 `systemctl status xray` 状态后再重试。配置校验或服务启动失败时应用会尝试自动回滚；仍无法恢复时，应先停止反复点击，保留错误信息并检查 VPS 上的 Xray 日志。

## 稳定性与性能设计

- 部署、模式切换和优化操作全局串行，避免连续点击造成并发重启
- 远程命令支持超时，SSH 连接失败会按策略重连并最终返回明确错误
- 每个部署步骤都会检查返回值，任一步骤失败都会终止后续流程，不会保存空凭证或误报成功
- Xray 配置采用临时文件、语法校验、原子替换、健康检查和失败回滚
- DNS 分流使用显式查询标签与路由规则，避免依赖 Xray 不支持的 `outboundTag` 字段
- 连接策略默认关闭 MUX，并将长连接半关闭回收参数设为更保守的值，减少资源占用

## 架构

```text
用户设备 (Windows/macOS/Android/iOS)
        │
        │ VLESS + Reality
        ▼
VPS 服务器运行 Xray-core
        │
        ├── ISP 代理模式 → ISP SOCKS5/HTTP 代理
        │
        └── 直连模式 → VPS 出口
```

## 配置与安全提示

VPS 密码、私钥路径、ISP 凭证和部署生成的 Reality 凭证由本地配置管理器保存于用户目录。1.2.16 起，配置内容通过 Electron `safeStorage` 使用操作系统安全存储能力加密，配置目录和文件在支持 POSIX 权限的平台上分别限制为 `0700` 和 `0600`；旧版明文配置会在首次读取时自动迁移。加密配置与当前系统账户绑定，不应直接复制到其他电脑。

请保护本机账户，不要把运行时配置文件、日志或构建产物中的敏感信息提交到公开仓库。公开发布前还应检查 Git 历史和远程服务器上的旧凭证是否需要轮换。
